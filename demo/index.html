SSE Lens — capture test page

Each button exercises a different capture path. Open the side panel first, then reload this page so the hook attaches before the page script runs.

This page needs a local server that streams; see demo/server.mjs. Serving this file over file:// will not work — Chrome forbids content scripts there, which the panel will tell you.

1 · fetch + text/event-stream

The ordinary case. Raw bytes are captured, so framing, comments and heartbeats all survive exactly as the server sent them. 


    


    

      
2 · fetch + OpenAI-style deltas

      

        Token-by-token choices[].delta.content. The Merged tab should reassemble the
        whole sentence and name the field it came from.
      

      
      

    


    

      
3 · fetch mislabelled as text/plain

      

        A proxy serving genuine SSE under the wrong content type. Captured only in
        loose mode, by sniffing the payload — strict mode should ignore it.
      

      
      

    


    

      
4 · EventSource

      

        The browser parses this one itself, so events are reconstructed and comments are
        structurally unavailable. The panel should say so rather than implying none were sent.
      

      
      
      

    


    

      
5 · XMLHttpRequest

      

        Captured from the growing responseText. Only the newly arrived slice is
        forwarded on each progress event, so frames must not appear duplicated.
      

      
      

    


    

      
6 · NDJSON

      
One JSON object per line, no data: prefix.

      
      

    


    

      
7 · Aborted mid-stream

      

        Aborts after ~1s. Should be recorded as aborted, not as an error, and the frames
        received before the abort must be kept.
      

      
      

    


    

      
8 · Truncated final frame

      

        Ends mid-event on purpose. The unterminated remainder should surface as a tail warning
        rather than being silently dropped.
      

      
      

    


    

      
9 · Ordinary JSON (control)

      

        Not a stream. Must not appear in the panel — this is the check that the
        hook is not capturing indiscriminately.
      

      
      

    


    

      
10 · Response fidelity (control)

      

        Asserts that the page still sees the correct status, url and full
        body after the hook rebuilt the response. Any failure here is a bug in the extension.
